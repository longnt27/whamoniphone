# Reproduction tools

- `kaggle/` builds and contains the notebooks used to select the detector/token
  interface and the output-only temporal filter.
- `evaluation/` contains their embedded evaluation/training modules and the
  final-evidence validator.
- `export/` converts the selected HMR2-S, residual adapter, and split WHAM
  components to Core ML.

Run all commands from the repository root. The final report documents the
licensed/private inputs that cannot be committed.
